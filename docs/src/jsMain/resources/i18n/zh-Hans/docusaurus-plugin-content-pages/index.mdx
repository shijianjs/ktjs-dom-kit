<ktjs-features section-title="它给你什么" tinted>

<ktjs-feature icon="lucide:box" title="用 Kotlin 写自定义元素">组件就是继承 `CustomElementAdapter` 的类，用 `defineIfMissing` 注册——没有 JS 类字面量，也不用给生命周期钩子起别名。</ktjs-feature>

<ktjs-feature icon="lucide:tag" title="属性就是状态">`attr` 委托直接读写 HTML attribute，标记、属性与渲染出的节点不可能对不上。</ktjs-feature>

<ktjs-feature icon="lucide:paintbrush" title="类型化样式表">`cssSheet { … }` 用 csstype 的值拼出 `CSSStyleSheet`，剩下的字符串只有类型表达不了的那些。</ktjs-feature>

<ktjs-feature icon="lucide:layers" title="没有 UI 运行时">节点建好就一直用，只做局部修改。没有 `render()`、没有 diff，底层也没有 Lit 或 React。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="在真实浏览器里测">用例跑在 Chromium 里，对着真元素、真属性变化——`MutationObserver` 不值得造假。</ktjs-feature>

<ktjs-feature icon="lucide:package" title="小封装的落脚点">API 只有十几个声明的封装，在这里拿一个模块，不必再开一套仓库、CI 和发布流程。</ktjs-feature>

</ktjs-features>
