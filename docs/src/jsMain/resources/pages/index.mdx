<ktjs-features section-title="What it gives you" tinted>

<ktjs-feature icon="lucide:box" title="Custom elements in Kotlin">A component is a class extending `CustomElementAdapter`, registered with `defineIfMissing` — no JavaScript class literal, no lifecycle aliases.</ktjs-feature>

<ktjs-feature icon="lucide:tag" title="Attributes are the state">The `attr` delegate reads and writes the HTML attribute, so the markup, the property and the rendered node cannot disagree.</ktjs-feature>

<ktjs-feature icon="lucide:paintbrush" title="Typed stylesheets">`cssSheet { … }` builds a `CSSStyleSheet` from csstype values; the only strings left are the ones no type can express.</ktjs-feature>

<ktjs-feature icon="lucide:layers" title="No UI runtime">Nodes are kept and mutated. No `render()`, no diffing, no Lit or React underneath.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested in a browser">The suite runs in Chromium against real elements and real attribute changes — a `MutationObserver` is not worth faking.</ktjs-feature>

<ktjs-feature icon="lucide:package" title="A home for small wrappers">A wrapper with a handful of declarations gets a module here instead of its own repository, CI and release pipeline.</ktjs-feature>

</ktjs-features>
